# Anugrah Malviya — Portfolio

Responsive static portfolio using plain HTML, CSS, and JavaScript; no package installation or build step is needed.

## Run locally

```powershell
python -m http.server 8000 --directory site
```

Open http://localhost:8000.

The manual-only Pages workflow is prepared but has not been run. Pages is not enabled. To publish, create the public repository, push this branch, set Pages to use GitHub Actions in repository settings, then manually dispatch the workflow.
